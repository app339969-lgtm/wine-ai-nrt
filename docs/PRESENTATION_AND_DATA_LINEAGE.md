## ส่วนที่ 2: พจนานุกรมคำศัพท์ภาษาอังกฤษบนสไลด์และหน้าเว็บ (อ่านว่าอะไร · แปลว่าอะไร)

### ก. หมวดการคลีนข้อมูล & สถิติ (Data Prep & Statistics)
| คำศัพท์ภาษาอังกฤษ | คำอ่านภาษาไทย | แปลว่าอะไร / อธิบายง่ายๆ เวลาพูด |
| :--- | :--- | :--- |
| **Primary Key (PK)** | ไพรมารี คีย์ | รหัสหลักที่ไม่ซ้ำกันเลยสักแถว เช่น `Transaction_ID`, `Customer_ID` ใช้ระบุตัวตน 1 รายการ |
| **Foreign Key (FK)** | ฟอเรนจ์ คีย์ | รหัสเชื่อมตาราง เช่น `Customer_ID` ในตารางบิล ที่ใช้วิ่งไปจับคู่กับตารางลูกค้า |
| **FK Match Rate** | เอฟเค แมตช์ เรต | อัตราการจับคู่เชื่อมตารางสำเร็จ ของเราได้ `100.0%` (50,000 / 50,000 บิลเชื่อมลูกค้าเจอครบ) |
| **Missing Values / Null (NaN)** | มิสซิ่ง แวลูส์ / นัล (แน็น) | ช่องข้อมูลที่ว่างหรือหายไป (เช่น ลืมกรอก) ของเราพบ 750 แถวที่หายพร้อมกัน 2 ช่อง |
| **Dual-Missing** | ดูอัล-มิสซิ่ง | การขาดข้อมูลพร้อมกัน 2 คอลัมน์สำคัญ คือหายทั้ง `Units_Sold` (จำนวนชิ้น) และ `Total_Amount` (ยอดเงิน) จึงคำนวณย้อนกลับไม่ได้ |
| **Imputation (Impute)** | อิมพิวเทชัน (อิมพิวต์) | การเติมค่าแทนช่องว่าง เช่น ใช้ค่าเฉลี่ย/มัธยฐานเติมลงไป (เราอธิบายว่าเลือก Drop 1.5% แทน Impute เพื่อไม่เดาจำนวนชิ้น) |
| **Outlier / Extreme Outlier** | เอาท์ไลเออร์ / เอ็กซ์ตรีม เอาท์ไลเออร์ | ค่าผิดปกติที่โดดออกจากกลุ่มมากเกินไป เช่น ปกติซื้อ 1–24 ชิ้น แต่มี 50 บิลที่คีย์ 999 / 1,200 / 1,500 ชิ้น |
| **IQR (Interquartile Range)** | ไอ-คิว-อาร์ (อินเทอร์ควอไทล์ เรนจ์) | ช่วงกระจายตัวตรงกลางของข้อมูล (`Q3 - Q1`) ใช้สร้างรั้วด้านบน (**Upper Fence** = อัปเปอร์ เฟนซ์ = 38.5 ชิ้น) เพื่อดัก Outlier |
| **Z-Score** | ซี-สกอร์ | ค่ามาตรฐานที่วัดว่าข้อมูลห่างจากค่าเฉลี่ยกี่เท่าของส่วนเบี่ยงเบน (`|Z| > 3` คือผิดปกติมาก) |
| **Mean / Average** | มีน / แอฟเวอเรจ | ค่าเฉลี่ยเลขคณิต (เอาผลรวมทั้งหมดหารด้วยจำนวนบิล) ข้อเสียคือถ้ามี Outlier ค่านี้จะโดนดึงสูงเกินจริง |
| **Median** | มีเดียน | ค่ามัธยฐาน (ค่าที่อยู่ตรงกลางเป๊ะเมื่อเรียงข้อมูล) ทนทานต่อ Outlier มาก (`฿1,035` เท่าเดิมทั้งก่อน-หลังคลีน) |
| **Std. Dev. (Standard Deviation)** | เอสทีดี เดฟ (สแตนดาร์ด ดีวิเอชัน) | ส่วนเบี่ยงเบนมาตรฐาน ใช้วัดว่าตัวเลขแกว่งตัวแรงแค่ไหน (หลังคลีนลดลง `-71.98%` เหลือ `฿4,399.19`) |
| **Pearson Correlation (r)** | เพียร์สัน คอร์ริเลชัน | ค่าความสัมพันธ์ระหว่างตัวแปร 2 ตัว มีค่า `-1` ถึง `+1` (`+0.8123` แปลว่าไปในทิศทางเดียวกันสูงมาก) |
| **Histogram** | ฮิสโตแกรม | กราฟแท่งแสดงความถี่ว่าแต่ละช่วงตัวเลขเกิดขึ้นกี่ครั้ง (เช่น จำนวนบิลที่ซื้อ 1 ชิ้น, 2 ชิ้น ... 24 ชิ้น) |
| **Audit Log / Audit Trail** | ออดิต ล็อก / ออดิต เทรล | บันทึกประวัติสำหรับตรวจสอบย้อนหลัง (เราแยก 50 Outliers มาไว้ใน `outliers_audit.csv` ไม่ได้ลบทิ้งเงียบๆ) |
| **Parity / DuckDB Parity** | แพรีตี / ดั๊กดีบี แพรีตี | ความเท่าเทียมตรงกัน 100% ระหว่างการคำนวณด้วย Pandas กับฐานข้อมูล DuckDB บนไฟล์ Parquet |

### ข. หมวดธุรกิจ ค้าปลีก และกลยุทธ์ (Business & Retail Analytics)
| คำศัพท์ภาษาอังกฤษ | คำอ่านภาษาไทย | แปลว่าอะไร / อธิบายง่ายๆ เวลาพูด |
| :--- | :--- | :--- |
| **Omnichannel** | ออมนิแชนเนล | การขายหลายช่องทางที่เชื่อมถึงกัน ทั้งออนไลน์ (`Online`) และหน้าร้าน (`In-Store`) |
| **Clean Revenue** | คลีน เรฟเวอนิว | รายได้สุทธิหลังตัดข้อมูลเสีย/ผิดปกติออกแล้ว (`฿142.16M`) |
| **AOV (Average Order Value)** | เอ-โอ-วี | ยอดซื้อเฉลี่ยต่อ 1 บิล (`รายได้รวม ÷ จำนวนบิล` = `฿2,889.36`) |
| **CLV (Customer Lifetime Value)** | ซี-แอล-วี | มูลค่ายอดซื้อรวมของลูกค้า 1 คนในช่วงเวลาที่ศึกษา (เฉลี่ย ~`฿142,000/คน/ปี`) |
| **Pareto Principle (80/20)** | กฎพาเรโต | กฎ 80/20 ที่บอกว่าผลลัพธ์ส่วนใหญ่ (~80%) มาจากปัจจัยส่วนน้อย (~20–35%) ของสินค้า |
| **Basket Size** | บาสเก็ต ไซส์ | ขนาดตะกร้าซื้อต่อบิล (ทั้งจำนวนชิ้นเฉลี่ย `12.50` ชิ้น และยอดเงินต่อบิล) |
| **High-Margin** | ไฮ-มาร์จิน | กลุ่มสินค้าที่ราคาต่อชิ้นสูง/ทำเงินก้อนใหญ่ให้ร้าน (`Household` ฿890, `Personal Care` ฿250) |
| **Traffic Driver** | แทรฟฟิก ไดร์เวอร์ | สินค้าที่ดึงคนเข้าร้านบ่อย (`Dry Food`, `Beverages`, `Snacks`) แม้ราคาต่อชิ้นถูกแต่มีบิลเยอะ |
| **Cross-Selling / Bundle** | ครอส-เซลลิง / บันเดิล | การขายพ่วง จับคู่สินค้าขายดีราคาถูก (อาหาร/เครื่องดื่ม) คู่กับสินค้ากำไรสูง (ของใช้ในบ้าน) เพื่ออัปยอดบิล |
| **O2O (Online-to-Offline)** | โอ-ทู-โอ | การดึงลูกค้าออนไลน์มาที่หน้าร้าน เช่น สั่งออนไลน์แล้วมารับที่สาขา (**Click & Collect** = คลิก แอนด์ คอลเลกต์) |
| **Time Series** | ไทม์ ซีรีส์ | ข้อมูลอนุกรมเวลาที่เรียงตามเดือน ม.ค.–ธ.ค. เพื่อดูว่าธุรกิจโตขึ้น ทรงตัว หรือตกลง |
| **QoQ (Quarter-over-Quarter)** | คิว-โอ-คิว | การเทียบยอดขายระหว่างไตรมาสหนึ่งกับอีกไตรมาสหนึ่ง เช่น Q4 เทียบ Q3 หรือ Q1 |
| **Low Season** | โลว์ ซีซัน | ช่วงเดือนที่ยอดขายซบเซากว่าปกติ ได้แก่ ก.พ. (`10.97M`), พ.ค. (`11.18M`), พ.ย. (`11.39M`) |
| **Loyalty Tier Paradox** | ลอยัลตี เทียร์ พาราด็อกซ์ | ความย้อนแย้งของระบบสมาชิก: ชื่อชั้นสูงขึ้น (Platinum vs Basic) แต่ยอดซื้อต่อคนแทบไม่ต่างกัน (+2.6%) |
| **Localized Promotion** | โลคอลไลซ์ โปรโมชัน | โปรโมชันที่ออกแบบเจาะจงเฉพาะพื้นที่/ภูมิภาค เช่น ลดค่าส่งเฉพาะภาคตะวันตกและใต้ |
| **What → So What → Now What** | วอท → โซ วอท → นาว วอท | กรอบเล่าเรื่องข้อมูล: **เกิดอะไรขึ้น (What) → สำคัญอย่างไร (So What) → ต้องทำอะไรต่อ (Now What)** |
